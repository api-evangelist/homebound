# Homebound

> Homebound is a tech-enabled, personalized homebuilder. It combines a proprietary
> software platform with a managed network of trade partners to build homes on a
> customer's lot, offer finished and in-progress inventory homes, and run disaster
> rebuild programs (notably wildfire recovery in California). Homeowners track budget,
> schedule, documents, and construction progress through a Homeowner Portal.

Note: Homebound does not publish a public developer API, developer portal, or API
documentation. The links below are the company's real public surfaces plus its
open-source engineering footprint. This file was generated by the API Evangelist
enrichment pipeline from the public company profile — it is not a vendor-published
llms.txt.
